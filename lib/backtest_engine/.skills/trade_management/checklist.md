# Trade Management Checklist

Verify these steps are completed at each stage of the trade lifecycle.

## 1. Position Verification
- [ ] Confirm entry fill price and quantity.
- [ ] Verify that a hard stop-loss is set.
- [ ] Record the initial risk limit (1R price).

## 2. Active Monitoring
- [ ] Calculate current R-multiple.
- [ ] Update Maximum Favorable Excursion (MFE) and Maximum Adverse Excursion (MAE).
- [ ] Check if the breakeven threshold has been reached.
- [ ] Check if trailing stop conditions are met.

## 3. Exit Validation
- [ ] Check time-based stop limits.
- [ ] Check underlying trend alignment.
- [ ] Check if the target price is hit.
- [ ] Verify execution costs are deducted on exit.
- [ ] Log trade metrics and exit reason.
