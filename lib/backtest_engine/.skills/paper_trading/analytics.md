# Paper Session Analytics Guide

Calculate performance metrics at the end of each paper trading session to evaluate system readiness.

## Performance Metrics
* **Expectancy**: Average return per trade.
* **Profit Factor**: Gross gains divided by gross losses.
* **Max Drawdown %**: Peak-to-trough drop in virtual capital.
* **Win Rate %**: Percentage of winning trades.
* **Execution Quality Score**: Measures simulated slippage against average spreads.
* **Live Readiness Assessment**: Verification that strategy meets deployment criteria.
