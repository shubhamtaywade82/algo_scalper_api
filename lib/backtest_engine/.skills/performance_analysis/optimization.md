# Performance Improvement Recommendations

Generate actionable recommendations to improve performance without overfitting.

## Recommendation Categories

1. **High ROI Modifications**:
   - Changes that significantly increase expectancy (e.g. "Move Call selection from 24300 OTM to 24200 ATM").

2. **Risk Mitigation**:
   - Exits that reduce drawdown length and depth (e.g. "Enforce EOD auto-squareoff at 15:10 instead of 15:15 to avoid EOD volume drop spreads").

3. **Cost Reduction**:
   - Rules to reduce trading frequency in high-slippage conditions (e.g. "Do not open new options positions during lunch hours").
