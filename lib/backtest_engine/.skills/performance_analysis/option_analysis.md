# Options Pricing & Greeks Analysis

For long option buying, analyze the impact of option greeks and pricing structures.

## Option Metrics

1. **Theta Decay (Time Decay)**:
   - Calculate total premium lost strictly to passage of time.
   - Evaluates if trades are held too long in low-volatility conditions.

2. **IV Expansion / Crush**:
   - Compare entry IV vs exit IV.
   - Identify if the strategy consistently buys expensive premiums that crush post-breakout.

3. **Strike Selection Performance**:
   - Compare performance of ATM vs OTM and ITM contracts.
   - Identify if OTM strikes decay too fast or if ITM contracts are illiquid.
