# Returns Analysis Guide

Evaluate portfolio profit returns systematically using the following metrics:

## Returns Metrics

1. **Compound Annual Growth Rate (CAGR)**:
   - Annualized rate of return. `CAGR = (EndingValue / StartingValue) ^ (1 / Years) - 1`.

2. **Rolling Returns**:
   - Evaluates return consistency across rolling windows (e.g. 3-month or 6-month holding periods).
   - Helps identify periods of underperformance.

3. **Daily / Monthly Profit Distribution**:
   - Plot returns to check for skewness and kurtosis. Option buying returns are typically positively skewed (long tail of large winners, small consistent losses).
