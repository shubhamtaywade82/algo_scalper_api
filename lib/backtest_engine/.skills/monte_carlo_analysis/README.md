# Monte Carlo Analysis

Probabilistic stress-testing laboratory for options trading strategies. Answers the question: *"What is the probability that this strategy survives under thousands of realistic alternative futures?"*

## Capabilities

- Trade shuffle, bootstrap, and block bootstrap simulation
- Regime-aware sampling (bull, bear, trending, range, high/low IV, weekly/monthly expiry)
- Execution simulation (slippage, spread, latency, partial fills)
- Portfolio simulation (position size, capital, risk %, max positions)
- Distribution estimation (returns, PnL, drawdown, capital, holding time)
- Stress testing (IV crush, theta acceleration, gap risk, liquidity collapse)
- Risk metrics (probability of ruin, drawdown risk, capital survival, Kelly stability)
- Output dashboard with deployment confidence scoring

## Institutional Extensions for Options
