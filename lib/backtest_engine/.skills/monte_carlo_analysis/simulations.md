# Simulations

Support multiple simulation methods.

## Trade Order Randomization

- Shuffle Trades
- Random Order
- Permutation
- Bootstrap

## Block Bootstrap

Maintain:

- Winning Streaks
- Losing Streaks
- Market Regimes
- Volatility Clusters

## Regime Simulation

Sample separately:

- Trending
- Range
- Bull
- Bear
- High IV
- Low IV
- Weekly Expiry
- Monthly Expiry

## Execution Simulation

Randomize:

- Slippage
- Spread
- Latency
- Fill Quality
- Rejected Orders
- Partial Fills

## Portfolio Simulation

Randomize:

- Position Size
- Capital
- Risk %
- Maximum Positions
- Daily Loss
- Portfolio Heat
